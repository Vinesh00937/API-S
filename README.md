# Assignment 1

This is a simple version of the assignment. The work is the same,
but the code is short and easy to understand.

- Task1: Flask + SQLite student API + Streamlit page
- Task2: API key protected text API, POST /process
- Task3: Login + admin/employee roles employee API

Run only one task at a time, because all tasks run on port 5000.
Press Ctrl + C to stop the previous task before starting the next one.

Task2: run `generate_keys.py` first to create the `.env` file.
The `.env` file contains private API keys and must not be pushed
to a public repo. Share keys with testers privately only.
